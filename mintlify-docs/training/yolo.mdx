<Note>
  YOLO is **optional**. The API and demo app work without it — they just won't include bounding box detections.
</Note>

## Label data with Roboflow

<Steps>
  <Step title="Create a Roboflow project">
    Sign up at [roboflow.com](https://roboflow.com) (free tier).
    Create new project → **Object Detection**.
  </Step>
  <Step title="Upload and label">
    Upload your document images. Draw bounding boxes:
    - Signatures → class `signature`
    - Stamps → class `stamp`

    Aim for at least **200–300 labelled images**.
  </Step>
  <Step title="Export">
    Export → **YOLOv8 format** → Download ZIP.
    Extract it — note the path to `data.yaml`.
  </Step>
</Steps>

---

## Train

```bash
python train_yolo.py --data path/to/data.yaml
python train_yolo.py --data path/to/data.yaml --device cpu
```

Best weights are automatically copied to `models/best.pt` after training.
