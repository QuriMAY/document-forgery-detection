## Architecture

```
Input (224×224 RGB)
       │
  ResNet backbone  ← pretrained on ImageNet
       │
  Global Average Pooling
       │
  Dropout(0.3) → Linear(→256) → ReLU → Dropout(0.2) → Linear(→2)
       │
  Softmax → [P(real), P(forged)]
```

---

## Command

```bash
make train

# Or with options
python train_classifier.py --device cpu
python train_classifier.py --resume models/classifier.pth   # continue from checkpoint
```

### AUC interpretation

| AUC | Quality |
|-----|---------|
| 0.70 – 0.79 | Acceptable |
| 0.80 – 0.89 | Good |
| 0.90+ | Excellent |

AUC is the primary metric — best AUC triggers a model checkpoint save.

## Training features

<CardGroup cols={2}>
  <Card title="Optimiser" icon="gears">
    AdamW with weight decay. OneCycleLR scheduler — warmup then cosine decay.
  </Card>
  <Card title="Class Balance" icon="scale-balanced">
    CrossEntropyLoss with per-class weights computed from the training set distribution.
  </Card>
  <Card title="Augmentation" icon="wand-magic-sparkles">
    Random crop, flip, colour jitter, rotation, grayscale, random erasing.
  </Card>
  <Card title="Early Stopping" icon="hand">
    Stops training if validation loss does not improve for `patience` epochs.
  </Card>
</CardGroup>
