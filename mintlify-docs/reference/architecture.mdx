## Detection pipeline

```
Input image (JPEG / PNG / WebP)
         │
         ▼
┌─────────────────────────────────────────────────────┐
│                  Analysis Pipeline                  │
│                                                     │
│  ELA Analyzer          ResNet Classifier            │
│  ─────────────         ──────────────────           │
│  re-compress           224×224 resize               │
│  abs diff × 15    +    ImageNet normalise           │
│  top-10% score         backbone + head              │
│  region contours       softmax P(forged)            │
│       │                      │                      │
│   ela_score (0–1)        cls_score (0–1)            │
│       └──────────┬───────────┘                      │
│                  │                                  │
│  combined = 0.35 × ela + 0.65 × cnn                │
│  verdict  = combined > 0.5 → FORGED                 │
│                                                     │
│  YOLOv8 Detector (optional)                         │
│  → signature bboxes + stamp bboxes                  │
└─────────────────────────────────────────────────────┘
```

## Components

| Component | File | Role |
|-----------|------|------|
| ELA Analyzer | `src/ela.py` | Detects JPEG compression inconsistencies |
| Classifier | `src/classifier.py` | ResNet inference wrapper |
| Detector | `src/detector.py` | YOLOv8 inference wrapper (graceful fallback) |
| Data Generator | `src/data_generator.py` | Copy-move + splice forgery synthesis |
| Utils | `src/utils.py` | Logging, config loader, .env loading |
| FastAPI | `api/main.py` | REST endpoint |
| Gradio app | `app.py` | Web demo interface |
| Training | `train_classifier.py` | Full training loop with MLflow + TensorBoard |
| Evaluation | `scripts/evaluate.py` | Test-set metrics + MLflow artifact upload |
