## What it does

Takes a document image as input and determines whether it has been tampered with using **three independent detection methods** combined into a single confidence score.

| Method | What it detects | Needs training |
|--------|----------------|----------------|
| **ELA** — Error Level Analysis | JPEG compression inconsistencies left by editing | No |
| **CNN** — ResNet Classifier | Whole-document real vs. forged classification | Yes |
| **YOLO** — Object Detector | Bounding boxes around signatures and stamps | Yes + labelling |

```
final_score = 0.35 × ela_score + 0.65 × cnn_score
verdict     = "FORGED" if final_score > 0.5
```

After running `make up`, six services are available:

## Quick install

```bash
git clone https://github.com/your-username/document-forgery-detection.git
cd document-forgery-detection

make venv && source forgery_env/bin/activate
make install
make up
```
