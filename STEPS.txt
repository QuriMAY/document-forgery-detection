================================================================================
  DOCUMENT FORGERY DETECTION SYSTEM — COMPLETE STEP-BY-STEP GUIDE
================================================================================

This file walks you through every step from a fresh clone to a fully trained
and running system.

--------------------------------------------------------------------------------
  WHAT THIS SYSTEM DOES
--------------------------------------------------------------------------------

  Takes a document image (invoice, contract, ID, etc.) and determines whether
  it has been tampered with. Three independent methods, one combined score:

  1. ELA  (Error Level Analysis)
       Detects JPEG compression inconsistencies caused by editing.
       Works on ANY image — zero training required.

  2. CNN  (ResNet Classifier)
       Trained neural network that classifies whole documents as
       real or forged. Main accuracy driver.

  3. YOLO  (Object Detector)  [optional]
       Draws bounding boxes around signatures and stamps.
       Requires manual labelling on Roboflow.

  Combined score = 0.35 × ELA + 0.65 × CNN
  Verdict: score > 0.5 → FORGED

  HOW THE TRAINED MODEL REACHES THE DEMO:
    1. You run: make train
    2. Best model saved to: models/classifier.pth
    3. Docker mounts: ./models:/app/models  (in docker-compose.yml)
    4. Demo checks for the file on every upload — picks it up automatically
    5. No restart needed — hot-reload is built in

================================================================================
  STEP 1 — CREATE THE VIRTUAL ENVIRONMENT
================================================================================

      make venv
      source forgery_env/bin/activate      # Windows: forgery_env\Scripts\activate

  You'll see "(forgery_env)" in your prompt when active.
  Re-activate every time you open a new terminal.


================================================================================
  STEP 2 — INSTALL DEPENDENCIES
================================================================================

      make install

  Installs: PyTorch, OpenCV, FastAPI, YOLOv8, MLflow, Gradio, Kaggle API,
            scikit-learn, TensorBoard, python-dotenv, tqdm, plotly, and more.

  Expected time: 3–10 minutes.


================================================================================
  STEP 3 — CONFIGURE YOUR KAGGLE API KEY
================================================================================

  3a. Create a free account at https://www.kaggle.com

  3b. Go to: https://www.kaggle.com/settings → Account → API → Create New Token
      Downloads kaggle.json.

  3c. Open .env in the project root:

      KAGGLE_USERNAME=your_kaggle_username
      KAGGLE_KEY=your_kaggle_api_key
      PYTHONPATH=.

  The .env file is in .gitignore — never committed.
  Scripts load .env automatically via python-dotenv.


================================================================================
  STEP 4 — DOWNLOAD TRAINING DATA
================================================================================

      make download

  Downloads 4 datasets from Kaggle:
    data/real/    ← invoices, letters, forms, scanned office documents
    data/patches/ ← signature images (used as splice donors)

  Quick test (300 per dataset):
      python kaggle_download.py --all --limit 300

  Log saved to:
      logs/kaggle_download/


================================================================================
  STEP 5 — GENERATE SYNTHETIC FORGED DOCUMENTS
================================================================================

      make generate

  Two forgery types:
    Copy-Move: copies a region from the same document and pastes elsewhere
    Splice:    pastes a region from a different document onto the target

  OUTPUT:
      data/generated/real/    ← copies of authentic images
      data/generated/forged/  ← newly created forgeries

  RECOMMENDED SIZES:
      Minimum: 300 + 300    Good: 1000 + 1000    Best: 3000+ per class

  Log saved to:
      logs/generate_synthetic_data/


================================================================================
  STEP 6 — SPLIT INTO TRAIN / VAL / TEST
================================================================================

      make split

  Stratified 70/15/15 split into:
      data/train/    data/val/    data/test/

  NEVER use test data during training — it is your honest final score.

  Log saved to:
      logs/prepare_dataset/


================================================================================
  STEP 7 — REVIEW config.yaml BEFORE TRAINING
================================================================================

  Key settings (already set for CPU):

      classifier:
        backbone: resnet18     ← fastest on CPU; use resnet50 for GPU
        batch_size: 16         ← lower to 8 if you run out of RAM
        epochs: 15             ← set to 5 first to verify pipeline works
        lr: 0.001
        patience: 10           ← early stopping

  GPU settings:
      backbone: resnet50
      batch_size: 32
      epochs: 30

    forgery_demo     http://localhost:7860       Gradio demo app ★

================================================================================
  HOW THE TRAINED MODEL REACHES THE DEMO
================================================================================

  This is important to understand:

  1. You train ON THE HOST (not in Docker):
         make train
         → saves models/classifier.pth

  2. The demo container mounts your models folder:
         volumes:
           - ./models:/app/models   ← in docker-compose.yml

  3. The demo checks for models/classifier.pth on EVERY upload.
     No restart needed — if you train while the demo is running,
     upload the next image and it will use the new model automatically.

  4. The demo sidebar shows model status:
       ✅ Loaded     ← model found and loaded
       ⚠️ Not trained yet  ← no model file, ELA-only mode

  WORKFLOW:
      make up          ← starts demo (ELA-only mode)
      make train       ← trains model on host, saves to models/
      (open localhost:7860 and upload a document)
      ← demo detects models/classifier.pth and uses it

================================================================================
  TROUBLESHOOTING
================================================================================

  "No images found in data/real/"
    → Run: make download

  "KAGGLE credentials not found"
    → Check .env has KAGGLE_USERNAME and KAGGLE_KEY
    → Run from the project root folder

  "Classifier model not found" in demo sidebar
    → Run: make train   (saves models/classifier.pth)
    → Upload an image in the demo — it detects the model automatically

  Training appears frozen
    → It is running — tqdm bars show per-batch progress
    → If you see no output at all, check logs/train_classifier/

  Out of memory
    → Lower batch_size in config.yaml (try 8 or 4)

  Docker service failing
    → make status    to see which container failed
    → docker logs forgery_<name> --tail 30    to see the error

  MLflow UI empty
    → Training must complete at least one epoch
    → Confirm mlflow.db exists in project root

  Grafana shows no logs
    → Start make up BEFORE running training
    → Promtail only ships lines written after it starts

  Mintlify docs fail to start
    → Container uses Node 20 — first start downloads mintlify (~60 seconds)
    → make logs to watch progress
