================================================================================
  DOCUMENT FORGERY DETECTION SYSTEM — COMPLETE STEP-BY-STEP GUIDE
================================================================================

This file walks you through every step from a fresh clone to a fully trained
and running system.

--------------------------------------------------------------------------------
  WHAT THIS SYSTEM DOES
--------------------------------------------------------------------------------

  Takes a document image (invoice, contract, ID, etc.) and determines whether
  it has been tampered with. It uses three independent methods:

  1. ELA  (Error Level Analysis)
       Detects JPEG compression inconsistencies caused by editing.
       Works on ANY image with zero training required.

  2. CNN  (ResNet Classifier)
       Trained neural network that classifies whole documents as
       real or forged. This is your main accuracy driver.

  3. YOLO  (Object Detector)  [optional]
       Draws bounding boxes around signatures and stamps.
       Requires manual labelling on Roboflow before training.

  Combined score = 0.35 × ELA + 0.65 × CNN
  Verdict: score > 0.5 → FORGED

  MLflow tracks every training run automatically.
  Grafana + Loki let you search all script logs in a browser.
  One command starts the entire stack: make up

================================================================================
  STEP 1 — CREATE THE VIRTUAL ENVIRONMENT
================================================================================

  A virtual environment isolates this project's packages from your system.
  Only needed once.

      make venv

  This runs:  python -m venv forgery_env

  Activate it every time you open a new terminal:

      Linux / Mac:   source forgery_env/bin/activate
      Windows:       forgery_env\Scripts\activate

  You'll know it is active when you see "(forgery_env)" in your prompt.


================================================================================
  STEP 2 — INSTALL DEPENDENCIES
================================================================================

      make install

  This runs:  pip install -r requirements.txt

  Installs: PyTorch, OpenCV, FastAPI, YOLOv8, MLflow, Kaggle API, Grafana
            client tools, scikit-learn, TensorBoard, python-dotenv, and more.

  Expected time: 3–10 minutes.

  If pip itself is outdated:
      forgery_env/bin/pip install --upgrade pip


================================================================================
  STEP 3 — CONFIGURE YOUR KAGGLE API KEY
================================================================================

  You need a Kaggle account to download datasets.

  3a. Create a free account at https://www.kaggle.com

  3b. Go to: https://www.kaggle.com/settings → Account → API → Create New Token
      This downloads kaggle.json.

  3c. Open .env in the project root and fill in:

      KAGGLE_USERNAME=your_kaggle_username
      KAGGLE_KEY=your_kaggle_api_key
      PYTHONPATH=.

      (The key is the long string from kaggle.json)

  The .env file is in .gitignore — it will never be committed.
  The scripts load .env automatically via python-dotenv.


================================================================================
  STEP 4 — DOWNLOAD TRAINING DATA
================================================================================

      make download

  This runs:  python kaggle_download.py --all

  Downloads 4 datasets:

    INTO data/real/  (authentic document images for CNN training):
      shaz13/real-world-documents-collections   — invoices, letters, forms
      patrickaudriaz/tobacco3482dataset          — scanned office documents

    INTO data/patches/  (signatures used as splice attack donors):
      robinreni/signature-verification-dataset
      ishanikathuria/handwritten-signatures

  OTHER OPTIONS:
      python kaggle_download.py --documents          # only real documents
      python kaggle_download.py --all --limit 300    # quick test (300 per dataset)
      python kaggle_download.py --all --limit 1000   # medium run

  HOW LONG:
      --limit 300:   2–5 minutes
      Full download: 20–60 minutes

  Log saved to:
      logs/kaggle_download/kaggle_download_YYYY-MM-DD_HH-MM-SS.log


================================================================================
  STEP 5 — GENERATE SYNTHETIC FORGED DOCUMENTS
================================================================================

      make generate

  This runs:
      python scripts/generate_synthetic_data.py \
          --real-dir data/real \
          --donor-dir data/patches \
          --num-forged 1000

  Two forgery types are created:
    Copy-Move:  Copies a region of the document and pastes it elsewhere.
    Splice:     Pastes a region from a different image over the document.

  OUTPUT:
      data/generated/real/    ← copies of real images
      data/generated/forged/  ← synthetic forgeries

  RECOMMENDED SIZES:
      Minimum viable:  300 + 300    (pipeline test)
      Good results:    1000 + 1000
      Best results:    3000+ per class

  Log saved to:
      logs/generate_synthetic_data/


================================================================================
  STEP 6 — SPLIT INTO TRAIN / VAL / TEST
================================================================================

      make split

  This runs:
      python scripts/prepare_dataset.py \
          --source-dir data/generated \
          --output-dir data

  Splits the data:
      train  70% — model learns from this
      val    15% — used after each epoch to detect overfitting
      test   15% — used ONLY at the end for the final honest score

  OUTPUT:
      data/train/real/    data/val/real/    data/test/real/
      data/train/forged/  data/val/forged/  data/test/forged/

  Log saved to:
      logs/prepare_dataset/


================================================================================
  STEP 7 — REVIEW config.yaml BEFORE TRAINING
================================================================================

  Key settings for CPU (already set as defaults):

      classifier:
        backbone: resnet18     ← fastest on CPU; use resnet50 for GPU
        batch_size: 16         ← lower to 8 if you run out of RAM
        epochs: 15             ← enough for a first run
        lr: 0.001
        patience: 10           ← stops early if val loss stalls

  When you get a GPU, change to:
      backbone: resnet50
      batch_size: 32
      epochs: 30


================================================================================
  STEP 8 — TRAIN THE CLASSIFIER
================================================================================

      make train

  This runs:  python train_classifier.py

  Resume from a checkpoint:
      python train_classifier.py --resume models/classifier.pth

  WHAT HAPPENS:
    • Each epoch = one full pass through all training images
    • Validation runs after each epoch
    • Best model (by AUC) saved to models/classifier.pth
    • All metrics auto-logged to MLflow and TensorBoard
    • Stops early if validation loss stops improving

  READING THE OUTPUT:
    Epoch   1/15 | TrLoss 0.6234 TrAcc 0.7123 | VlLoss 0.5891 VlAcc 0.7450 VlF1 0.7312 VlAUC 0.8102 | 45.3s

    AUC ranges:
      0.70–0.79  Acceptable
      0.80–0.89  Good
      0.90+      Excellent

  EXPECTED TIME (CPU):
    ResNet18, 1000 images, 15 epochs  →  30–60 minutes
    ResNet50, 3000 images, 30 epochs  →  3–6 hours

  WHAT IS LOGGED TO MLFLOW AUTOMATICALLY:
    Params:   backbone, batch_size, lr, epochs, image_size, device
    Per epoch: train_loss, train_acc, train_f1, val_loss, val_acc,
               val_f1, val_auc, lr, epoch_time_s
    Artifact: models/classifier.pth (on best AUC)
    Final:    best_val_auc, best_epoch, early_stopped

  Log saved to:
      logs/train_classifier/


================================================================================
  STEP 8.5 — MLFLOW EXPERIMENT TRACKING UI
================================================================================

  MLflow is started automatically with `make up` at port 5000.
  Or run standalone on the host:

      mlflow ui --backend-store-uri sqlite:///mlflow.db
      Open: http://localhost:5000

  WHAT YOU CAN DO:

    Runs table
      • Every training run shown as a row
      • Sort by val_auc to instantly find your best model
      • Run name format: resnet18_bs16_lr0.001

    Compare runs
      • Tick 2+ runs → Compare → overlaid metric charts

    Run detail
      • Full per-epoch metric history
      • Artifacts tab → download classifier.pth or view plots

    Search
      • metrics.val_auc > 0.85
      • params.backbone = "resnet50"

  After running scripts/evaluate.py, an "evaluation" run appears with:
    test_auc, test_accuracy, confusion_matrix.png, roc_curve.png, pr_curve.png


================================================================================
  STEP 9 — EVALUATE THE TRAINED MODEL
================================================================================

      make evaluate

  This runs:  python scripts/evaluate.py --test-dir data/test

  OUTPUT in evaluation/:
      confusion_matrix.png   TP / FP / TN / FN counts as a colour grid
      roc_curve.png          ROC curve with AUC score
      pr_curve.png           Precision-Recall curve with Average Precision
      report.txt             Full per-class classification report

  All four files are also uploaded to MLflow as artifacts.

  READING THE CONFUSION MATRIX:
                    Predicted Real   Predicted Forged
      Actual Real        TN               FP
      Actual Forged      FN               TP

      FP = real docs wrongly flagged (annoying)
      FN = forged docs missed (dangerous — minimise these)

  Log saved to:
      logs/evaluate/

  STEP 10 — RUN THE VISUAL DEMO
================================================================================

  This runs:  python demo.py

================================================================================
  STEP 11 — (OPTIONAL) TRAIN YOLO FOR STAMP/SIGNATURE DETECTION
================================================================================

  YOLO adds bounding boxes around signatures and stamps.
  Skip this if you only need the real/forged verdict.

  11a. Create a free account at https://roboflow.com
  11b. New project → Object Detection
  11c. Upload document images, draw boxes:
         Signatures → label "signature"
         Stamps     → label "stamp"
         Aim for 200–300 labelled images minimum.
  11d. Export → YOLOv8 format → Download ZIP
       Extract it — you'll find data.yaml inside.
  11e. Train:

           python train_yolo.py --data path/to/data.yaml

  Best weights auto-copied to models/best.pt.
  The API and inference.py detect and load it on next startup.

  Log saved to:
      logs/train_yolo/


================================================================================
  STEP 12 — RUN INFERENCE ON YOUR OWN DOCUMENTS
================================================================================

  Single image:
      python inference.py path/to/document.jpg

  Entire folder:
      python inference.py path/to/folder/

  Save results to JSON:
      python inference.py path/to/folder/ --output results.json

  Save ELA visualisation:
      python inference.py path/to/document.jpg --visualize

  OUTPUT:

================================================================================
  TROUBLESHOOTING
================================================================================

  "No images found in data/real/"
    → Run: make download

  "KAGGLE credentials not found"
    → Check .env has KAGGLE_USERNAME and KAGGLE_KEY
    → Run from the project root folder

  "Classifier model not found"
    → Run: make train   (creates models/classifier.pth)

  Training loss not decreasing
    → Dataset too small. Use --limit 1000 in kaggle_download.py
    → Verify both train/real/ and train/forged/ have images

  Out of memory during training
    → Lower batch_size in config.yaml (try 8 or 4)

  "ModuleNotFoundError: No module named 'src'"
    → Make sure PYTHONPATH=. is in .env
    → Or: export PYTHONPATH=.

  Very slow training on CPU
    → Expected. ResNet18 + 1000 images + 15 epochs ≈ 30–60 min
    → Set epochs: 5 first to confirm the pipeline works
    → For real training, use Google Colab (free T4 GPU) — same code, no changes

  Docker services not starting
    → Run: make status   to see which container failed
    → Run: make logs     to see error output

  MLflow UI is empty (no runs)
    → Confirm make up ran successfully and mlflow.db exists
    → Training must complete at least one epoch to create a run

  Grafana shows no logs
    → The stack must be running (make up) BEFORE you run training scripts
    → Promtail only picks up new lines written after it started
    → Existing .log files in logs/ are still readable manually
